# 🎌 みんなの日本語 — แบบฝึกหัดบทที่ 4–6

เว็บแอปฝึกทำข้อสอบภาษาญี่ปุ่นสำหรับผู้เรียนหนังสือ **みんなの日本語 初級 I** โดยครอบคลุมเนื้อหาบทที่ 4, 5 และ 6 ทั้งคำศัพท์ ไวยากรณ์ คำอนุภาค และสำนวน

**Live demo:** [https://document-ten-phi.vercel.app](https://document-ten-phi.vercel.app)

---

## ฟีเจอร์

| แท็บ | รูปแบบ | คำอธิบาย |
|------|--------|-----------|
| 📚 1. ญี่ปุ่น→ไทย | Flash card + พิมพ์ตอบ | สุ่มคำศัพท์ทีละคำ ครบทุกคำก่อนรีเซ็ต |
| ✍️ 2. ไทย→ญี่ปุ่น | พิมพ์ฮิรางานะ | แปลจากไทยเป็นญี่ปุ่น |
| 🀄 3. อ่านคันจิ | พิมพ์ฮิรางานะ | ฝึกอ่านตัวคันจิและวันที่พิเศษ |
| ✏️ 4. ประโยค | เลือกตอบ + เติมคำ | โครงสร้างประโยคบทที่ 4–6 |
| 🔗 5. คำเชื่อม | เติมคำในช่องว่าง | ฝึกใช้อนุภาค に・で・へ・から・まで ฯลฯ |
| 💬 6. สำนวน | เลือกตอบ | สำนวนและรูปแบบสนทนา |
| 📝 7. เขียนประโยค | เขียนอิสระ + ดูเฉลย | ฝึกแต่งประโยคภาษาญี่ปุ่น |
| 📋 รายการคำศัพท์ | ตาราง | ดูคำศัพท์ทั้งหมดแยกตามบทเรียน |

### ระบบ Flash Card (แท็บ 1)
- สุ่มคำศัพท์จาก pool กว่า **115 คำ** ครอบคลุมบทที่ 4, 5, 6
- ไม่ซ้ำคำจนกว่าจะครบรอบ
- แสดงคันจิ hint เฉพาะตัวที่กำหนดเท่านั้น (18 ตัวจาก kanji.pdf)
- นับคะแนนและแสดง progress bar

### รายการคำศัพท์
- กรองตามบทเรียน: บทที่ 4 / 5 / 6 / ทั้งหมด
- แสดงฮิรางานะ, คันจิ (ถ้ามี), และความหมายภาษาไทย

## โครงสร้างโปรเจกต์

```
.
├── practice.html   # ไฟล์ต้นฉบับ (แก้ไขที่นี่)
├── index.html      # สำเนาสำหรับ Vercel (sync จาก practice.html)
├── vercel.json     # Vercel static deployment config
└── README.md
```

> **หมายเหตุ:** ไฟล์ PDF ต้นฉบับ (みんなの日本語 ฉบับภาษาไทย) ไม่ได้รวมอยู่ใน repository

## การ Deploy

โปรเจกต์ deploy บน **Vercel** เป็น static site

```bash
# อัปเดตและ deploy ใหม่
cp practice.html index.html
git add practice.html index.html
git commit -m "your message"
git push
vercel deploy --yes
```
